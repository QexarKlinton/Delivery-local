# Delivery Local

## Descripción

Delivery Local es una plataforma web desarrollada con fines académicos para gestionar solicitudes de entrega de productos y servicios dentro de una comunidad local. El sistema busca centralizar el registro de usuarios, la administración de pedidos y el seguimiento de las solicitudes realizadas por los clientes.

Actualmente el proyecto se encuentra en fase de desarrollo de un Producto Mínimo Viable (MVP), enfocado en validar las funcionalidades esenciales de gestión y operación.

---

## Problemática

Muchos negocios y usuarios gestionan pedidos mediante llamadas telefónicas o mensajes instantáneos, lo que dificulta el seguimiento de solicitudes, el control de información y la organización de entregas.

Delivery Local propone una solución digital que permita registrar, administrar y consultar información de manera centralizada.

---

## Objetivo General

Desarrollar una plataforma web que facilite la gestión de solicitudes de entrega local mediante una interfaz organizada, accesible y escalable.

---

## Objetivos Específicos

- Permitir el registro y administración de usuarios.
- Gestionar la información de pedidos dentro del sistema.
- Centralizar la consulta y almacenamiento de datos.
- Aplicar buenas prácticas de desarrollo y control de versiones.
- Mantener documentación técnica durante el ciclo de desarrollo.
